What it does. A random forest on flattened window features — the strong classical-ML reference: no architecture tuning, no GPU, surprisingly hard to beat on tabularised waveform statistics. Trains in minutes on CPU.

Reference: Breiman, Machine Learning 2001 · Implementation: src/evemtbench/baselines/random_forest.py

Note: transfer protocols need transferable weights, so they apply only to the deep baselines mlp/gru/cnn/resnet (coverage.baseline_applies).
