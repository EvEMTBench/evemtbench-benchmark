benchmark version 1.1.0 · held_out results v1.0.0 · splits v1.0/held_out, v1.1/multi_grid
updated 2026-11-10 07:35 UTC · git b4dcdf9ee26d
What it does. A multi-layer perceptron on the flattened window. The simplest learned neural baseline: no temporal inductive bias, so it measures how far raw capacity gets without architecture. Its parameter count grows with the global view width, which is why it is the largest model on ieee39.

Reference: Rumelhart et al., Nature 1986 · Implementation: src/evemtbench/baselines/mlp.py
