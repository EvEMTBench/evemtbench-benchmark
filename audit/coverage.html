A cell is one (task × protocol × grid × baseline) runner invocation; it is done only when every expected test-set result.json is valid. Three non-green states are kept distinct and none is hidden: pending (queued sweep work), failed (partial artifacts), and N/A (excluded by a stated applicability rule, not missing).

  • pretrain_grid_only — multi_grid_pretrain runs only on the template_20kv/template_110kv corpora; held_out and the transfer protocols run only on the four reference grids (coverage.protocol_grid_applies)
  • threshold_scope — threshold is a single-terminal overcurrent relay rule — it applies only to the binary local fault-detection task (coverage.baseline_applies)
  • transfer_deep_only — transfer protocols need transferable weights, so they apply only to the deep baselines mlp/gru/cnn/resnet (coverage.baseline_applies)
