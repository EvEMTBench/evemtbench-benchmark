benchmark version 1.1.0 · held_out results v1.0.0 · splits v1.0/held_out, v1.1/multi_grid
updated 2026-08-18 08:33 UTC · git 2b3caf756827
What it does. Predicts the most frequent training class for every window (or the training-mean for regression). It contains zero information about the input and exists as the analytic chance floor: its balanced accuracy must equal 1/k, which the floor gate checks. Any model worth reporting must clear it.

Reference: trivial floor (analytic) · Implementation: src/evemtbench/baselines/majority.py

Note: transfer protocols need transferable weights, so they apply only to the deep baselines mlp/gru/cnn/resnet (coverage.baseline_applies).
